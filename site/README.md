## Machine and bot discovery

The production package intentionally exposes machine-readable context so search engines, AI crawlers, assistants, and agents can correctly interpret MJC capabilities and boundaries.

Primary files:

- `llms.txt` — canonical bot/LLM-oriented capability description
- `robots.txt` — crawler access policy
- `sitemap.xml` — discoverable route inventory
- JSON-LD in public HTML — structured organization/person/service context
- canonical, OpenGraph, and social metadata

Machine-readable copy must distinguish operational, bounded, prototype, and planned functionality and must not convert roadmap items into production claims.

## Build and deployment relationship

Repository-level deployment configuration lives outside this directory.  The root build process copies `/site` into the deployable output directory used by Vercel.

Changes to public copy, metadata, routes, bot-discovery content, or conversion paths remain subject to repository security and content-governance controls.
